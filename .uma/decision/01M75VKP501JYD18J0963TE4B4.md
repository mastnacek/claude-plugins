Decided by the user on 2026-11-11 (resolves the review task about cc-prompt-translate translating dialog answers and fact content).

- **Storage language:** UMA facts (title, body, tags) are written in **English**, even when the user writes in Czech, so the model understands them best. Same convention as pi-uma ("The operator writes and reviews facts in English").
- **Display:** the user sees facts **translated into Czech** — in the write-approval dialog, in `/uma review` and in the `/uma search|list|read|timeline` outputs. The translation is done by the **cc-uma-memory plugin itself** (port of pi's `src/slices/translate`), not by cc-prompt-translate.
- **Invariant (from pi):** translation never touches stored data — the approved fact is the original English text (or the user's edit of it); the model keeps reading the original.
- Switch `/uma lang cs|en` (default `cs`; `en` = no translation).
- Text the user types into a dialog field may be translated into English by cc-prompt-translate — that is now desirable and is not blocked.
- Older Czech facts in this project were superseded by English versions on 2026-11-11.
